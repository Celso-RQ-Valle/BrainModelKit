# Security policy

## Supported versions

BrainModelKit is currently pre-release software. Security fixes are applied to
the latest released version only.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Security** tab by
selecting **Report a vulnerability**. Do not disclose a suspected vulnerability
in a public issue.

Include the affected version, reproduction steps, potential impact, and any
suggested mitigation. You should receive an acknowledgment within seven days.
